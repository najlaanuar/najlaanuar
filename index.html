Perpustakaan Sederhana

Perpustakaan Sederhana merupakan aplikasi manajemen katalog berbasis web yang dirancang untuk mempermudah pengelolaan data buku dan riwayat peminjaman secara efisien. Mengusung konsep operasi CRUD (Create, Read, Update, Delete) dasar, sistem ini menyediakan antarmuka yang intuitif dan mudah digunakan untuk menangani administrasi perpustakaan harian

PHP MySQL Bootstrap Html5 CSS3 JavaScript

Web Layanan Pengaduan Masyarakat Sedehana

Platform web ini dibangun untuk memfasilitasi masyarakat dalam menyampaikan aspirasi, laporan, serta pengaduan secara terstruktur. Mengutamakan performa yang cepat dan desain yang responsif di berbagai perangkat, sistem ini memastikan setiap masukan dari masyarakat dapat tersampaikan dengan lancar melalui antarmuka yang modern dan ramah pengguna.

PHP MySQL Bootstrap Html5 CSS3 JavaScript

Web Reservasi Hotel Sederhana

Web Reservasi Hotel Sederhana adalah sistem alur pemesanan kamar hotel yang menitikberatkan pada kesederhanaan transaksi tanpa integrasi pembayaran eksternal. Sistem ini bekerja dengan menerbitkan tiket digital berbasis barcode setelah proses pemesanan, di mana pemindaian barcode tersebut akan secara otomatis memperbarui dan mengurangi jumlah stok kamar yang tersedia secara real-time.

PHP MySQL Bootstrap Html5 CSS3 JavaScript

Cash Advance System

Cash Advance System merupakan aplikasi manajemen keuangan operasional internal yang dirancang untuk menangani alur pengajuan serta pelaporan biaya perjalanan dinas. Selain itu, sistem ini juga memfasilitasi administrasi pembayaran inventaris dan vendor, sehingga seluruh proses pencairan serta pertanggungjawaban dana perusahaan dapat terdokumentasi dengan rapi dan terpusat.

.Net C# SQL Server Html5 CSS3 JavaScript

Web Perjalanan Dinas dan Budgeting

Aplikasi ini merupakan pengembangan dari sistem perjalanan dinas yang dilengkapi dengan modul kontrol anggaran (budget control) secara ketat. Berbeda dengan sistem cash advance biasa, web ini memiliki aturan validasi khusus di mana pengguna tidak dapat membuat pengajuan perjalanan dinas jika alokasi anggaran tidak mencukupi atau kosong, sehingga membantu perusahaan menjaga efisiensi serta akuntabilitas alokasi dana operasional.

.Net C# SQL Server Html5 CSS3 JavaScript

NR Journey

NR Journey adalah platform all-in-one travel booking yang menyajikan solusi praktis bagi wisatawan untuk memesan paket perjalanan lengkap di Indonesia tanpa perlu mengurus reservasi secara terpisah. Aplikasi ini mengintegrasikan pemesanan penginapan, tiket tempat wisata, dan layanan tour guide dalam satu alur terpadu. Sistem reservasinya bekerja hingga penerbitan barcode konfirmasi yang secara otomatis mengurangi kuota pemesanan yang tersedia.

Data & Analytics Projects

Enterprise Data Pipeline & Analytics Platform

Merancang dan mengimplementasikan end-to-end ETL data pipeline terotomatisasi menggunakan Apache NiFi dan Apache Airflow untuk proses penyerapan serta penarikan data cuaca, coal dan berita secara terintegrasi. Proyek ini mencakup pemrosesan data mentah melalui skrip Python dan query SQL tingkat lanjut berbasis regex filtering untuk pembersihan serta transformasi data. Implementasi pipeline ini berhasil mengeliminasi proses penarikan data manual secara total, menjaga keandalan penyerapan data yang terstruktur, dan memastikan ketersediaan data siap analisis secara konsisten sesuai dengan standar regulasi data governance perusahaan.

Python PostgreSQL Airflow Apache Nifi Docker Superset
